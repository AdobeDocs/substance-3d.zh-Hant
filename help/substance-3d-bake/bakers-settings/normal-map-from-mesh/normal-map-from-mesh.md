# 從網格取得的法線貼圖

Mesh Baker 的法線貼圖可以讓你從高多邊形網格建立切線空間或世界空間法線貼圖。**提供：**

* 物質畫家
* 物質設計師
* 物質自動化工具包

## 參數

| *參數* | *描述* |
| --- | --- |
| **地圖類型** | 控制烘焙者應該輸出哪種類型的法線紋理。可能的數值：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>世界空間</strong></li><li data-preserve-html="true"><strong>切空間</strong> （預設）</li></ul>*在 Substance Painter 中，此參數無法被控制，並設為切線空間。* |
| **正常方向** | 若將 **貼圖類型** 參數設為切線空間，定義法線貼圖的格式。可能值：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>OpenGL</strong></li><li data-preserve-html="true"><strong>DirectX</strong> （預設）</li></ul>*在 Substance Painter 中，這個參數是由 [專案設定](https://experienceleague.adobe.com/zh-hant/docs/substance-3d-painter/using/interface/project-configuration)控制的。* |
