# 將 UV 轉換成 SVG

將 UV 轉換成 SVG 的烘焙工具會將低多邊形網格 UV 轉換成向量圖形檔案。 這個向量圖形檔案可以用來建立遮罩。

**可於以下媒體取得：**

* 物質設計師
* 物質自動化工具包

## 參數

| *參數* | *描述* |
| --- | --- |
| **填充物** | 控制要在 SVG 圖形中加入多少幾何填充。 |
| **彩色模式** | 定義了 SVG 形狀應該如何著色。可能的數值：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>隨機：</strong> 每個 UV 殼層都被隨機顏色染色。</li><li data-preserve-html="true"><strong>HUE Shift：</strong> 每個 UV 殼體都以獨特的色調值著色。</li><li data-preserve-html="true"><strong>灰階：</strong> 每個 UV 殼層都以獨特的灰階值著色。</li><li data-preserve-html="true"><strong>均勻色彩：</strong> 所有紫外線外殼都以50%的灰值著色。</li><li data-preserve-html="true"><strong>材質 ID 顏色</strong>：UV 殼體依照場景檢視中定義的材質顏色來著色。</li></ul> |
