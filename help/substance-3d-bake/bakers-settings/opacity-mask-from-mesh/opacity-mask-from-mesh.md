# 來自網格的不透明度遮罩

mesh baker 的不透明度遮罩會計算一個紋理，將錯過的光線轉換成灰階二進位影像。 此紋理通常用作不透明度貼圖。

紋理屬性定義為：

* 黑色值代表空白區域。
* 白色值代表凸面。

**提供：**

* 畫家
* 設計師
* 自動化工具包
