# 如何匯出烘焙好的地圖？

>[!WARNING]
>
> **問題**
> 
> 我該如何將我從網格烘焙的材質匯出到其他應用程式中？

>[!NOTE]
>
> **解決方案：Substance Designer**
> 
> Baker 的輸出檔案應該位於網格連結的 Substance 圖旁邊。 右鍵點擊並選擇「探索」，即可在應用程式的檔案總管視窗中查看檔案。

>[!NOTE]
>
> **解答：物質畫家**
> 
> Baker 的輸出檔案會儲存在專案檔案（\*.spp）中。 要匯出它們，可以以下方式：
> 
> * 使用 **檔案>「匯出貼圖** 」對話框，選擇匯出預設「網格貼圖」
> * 在書架中右鍵點擊烘焙的材質，選擇「匯出」。

>[!NOTE]
>
> **解決方案：物質自動化工具包**
> 
> Baker 的輸出檔案預設會儲存在網格旁邊。 輸出資料夾可以透過命令列中的特定參數來更改。
