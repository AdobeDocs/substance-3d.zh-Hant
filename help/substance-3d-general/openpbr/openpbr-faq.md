# OpenPBR 常見問題

## OpenPBR 模型

+++什麼是 OpenPBR？Painter 支援哪個版本？

OpenPBR 是由學院軟體基金會（Academy Software Foundation）主辦的開放材料規範，定義了一個標準化的著色模型，設計上能在不同應用程式間一致運作。 [Painter 的文件中有更多關於使用 OpenPBR](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/home) 的資訊。

+++

+++當一個應用程式聲稱「支援 OpenPBR」是什麼意思？我該如何了解某個特定應用程式對它的支援程度？

沒有正式的認證程序，因此理賠可能有不同的含義。 實務上，實作方式各異：有些涵蓋完整規格，有些只涵蓋部分，遺漏薄膜、色散或某些次表面行為等特徵。 另外請注意，「MaterialX 支援」與「OpenPBR 支援」並不相同;應用程式可能支援其中一種，但未完全實作另一種。

要了解特定應用程式實際支援什麼，可以結合多種方法：查看發佈說明（支援通常是逐步增加）;載入 ASWF 的 OpenPBR Shader Playground，並快速與參考渲染與表面間隙比較;或者對於有大量開發流程投資的工作室，直接詢問廠商支援的功能及其路線圖。

+++

+++OpenPBR 能否保證不同應用程式和渲染器之間呈現相同的結果？

不完全是，這是刻意設計的。 OpenPBR 定義了共享材質模型，但最終外觀也會受到光照、渲染演算法、色彩管理，以及每個實作是否符合規格的決定。

實務上，最大化這種保證意味著：透過 MaterialX 整合的美元匯出;提前使用 ASWF 的 OpenPBR Shader Playground 驗證往返行程，而非在生產結束時;確認廠商對你所使用任何進階功能的支援程度;並事先同意哪些功能會在共享材料中使用，哪些不使用。 可攜性應該被積極驗證，而非假設。

+++

+++有沒有 OpenPBR 無法準確呈現的教材？

是的。 OpenPBR 是一個參數化模型。 粗糙度、金屬度與IOR等參數涵蓋絕大多數生產應用，但無法複製像X-Rite AxF這類從實體樣品中擷取實際光學數據的材料格式的精確度。 對於一般生產工作，OpenPBR 非常適合使用;對於需要精確樣本匹配的應用，測量格式可能更為適合。

汽車油漆是一個很好的例子。 在 OpenPBR 中可以製作汽車塗裝，但有幾個注意事項。 OpenPBR 沒有內建專用的汽車塗裝著色器，因此對某些汽車產業的用途來說可能不夠。 此外，這也取決於汽車油漆的種類——有些汽車油漆的特性總是超出任何特定著色器的範圍。 但考慮到這些點，汽車塗裝自然地映射到 OpenPBR 的分層架構上。

+++

## 設置與轉換

+++我需要學習 OpenUSD 或 MaterialX 才能使用 OpenPBR 嗎？

不。 對大多數藝術家來說，OpenPBR 只是內建在他們現有工具中的材質模型。 Substance 3D Painter、Maya 2025.3 和 3ds Max 2026 都使用 OpenPBR 作為預設材質;使用它只是代表使用標準著色器。 USD和MaterialX只有在材料需要在不同應用間移動時才變得重要。 對於單一應用程式的工作流程，原生支援已足夠;對於多 DCC 管線，USD 與 MaterialX 提供交換基礎設施，但多半在幕後運作。

話雖如此，最穩健的共享素材庫交換路徑是透過 MaterialX 整合的 USD，該系統提供一個標準化、不依賴渲染器的材質描述容器。 將資料匯出為獨立資產（無相關模型，用於共享函式庫）的工作流程仍在積極開發中，尚未在全球全面支援。 在承諾依賴此技術的函式庫架構之前，先驗證你的具體管線與現有能力的關聯。

+++

+++我該如何在 Substance 3D Painter 中建立一個新的 OpenPBR 專案？

未使用範本的專案預設使用 OpenPBR 著色器。 OpenPBR 著色器現在是新專案視窗的第一個選項，取代了 ASM。 也有專門的範本可用於特定工作流程（各向異性、塗層、模糊、次表面散射），且匯入包含 OpenPBR 材質的 USD 檔案會自動設定專案。 Substance 3D Painter 附帶的範例專案也已更新，採用 OpenPBR 工作流程，是熟悉其實務運作的好方法。

+++

+++我可以將現有的 Adobe Standard Material（ASM）專案轉換成 OpenPBR 嗎？

沒有自動轉換。 現有的 ASM 專案在開啟時會保留目前的著色器，而新專案則保留 ASM 範本。

若要手動遷移到 OpenPBR，請在著色器設定視窗中選擇 OpenPBR 著色器，然後透過貼圖集設定新增或移除通道，新增 OpenPBR 通道> 完成後，檢視現有圖層，確保內容鎖定目標頻道。

+++

+++我的自訂著色器需要更新以支援 OpenPBR 嗎？

不——現有的自訂著色器仍然有效，因為相關的著色器函式庫是被棄用而非移除。 不過建議遷移到新的著色器函式庫;它們更乾淨且易於操作。 詳情請參閱說明選單中的著色器 API 變更日誌。

+++

## 應用程式內使用

+++OpenPBR 有這麼多參數，我應該把重點放在哪裡？

從簡單開始。 對於大多數不透明表面，底色、鏡面粗糙度和金屬度解釋了材料間大部分的可見差異。 若反射率準確度重要，則加入鏡面色;若材料有掠角色調，則細化鏡面色。 只有在有明確且以參考為基礎的理由時，才啟用透射、次表面、塗層、模糊、薄膜和色散，因為每增加一個通道都會增加複雜度和潛在的渲染成本。 隱藏或收合未使用的參數群組，能讓你的工作區保持專注，並降低意外影響的風險。

+++

+++我有一個粗糙度貼圖——我應該把它接到 Base Diffuse Roughness 還是 Specular Roughness？

鏡面粗糙度（Specular Roughness）— 這控制反射銳利度，是其他 PBR 工作流程中粗糙度輸入的直接對應。 基礎漫反射粗糙度是一個獨立且專門的參數，僅影響漫反射散射;對大多數工作流程而言，它可維持在預設狀態。

+++

+++為什麼當我使用次表面散射時，改變基底色卻沒有任何效果？

有一個「優先順序的層級」決定每個參數對材料最終外觀的影響程度。 像這樣：

* 金屬性優先：當金屬性=1時，次表面和傳輸部分會被關閉。
* 接著是傳輸重量：若傳輸重量=1，則不存在次表面重量。
* 接著是《次表重量》。
* 擴散底色是最後：底色擴散只有在上述條件都未設為1時才會貢獻。

因此，在上述例子中，若 Subsurface Weight 設為 1（最大值），則它控制所有外觀。 改變基礎色彩值沒有影響，因為基礎擴散基本上沒有貢獻。 反之，若金屬度設為最大值1，則改變透光權重、次表面重量與漫反射基底色的數值，對材料的最終外觀不會有任何影響。 透光、次表面和漫反射都是介電（非金屬），所以將金屬度設為1就是移除任何非金屬的貢獻。

+++

+++為什麼變速會表現得出乎意料？ 例如，為什麼當我啟用它時，網格看起來會非常暗？

最常見的原因是傳輸深度設定得太低。 此參數定義光線在透射色達到完全飽和前的傳播距離;在低值下，即使是薄的幾何圖形也會顯得暗且密集。 將它放大到與物件大致物理比例相符。 如果材質看起來太清澈，則同時調整透射色與深度，找到合適的平衡。

散射還能增加更多複雜度。 透射色並非簡單的色調——其效果取決於光線穿過物體的距離，由透射深度控制。 散彩色彩則控制著光線可走的另一條路——在材質內彈跳，而非直接穿透。 因為散射是有方向性的，結果也會根據光源的位置而改變。 調整其中一項而不考慮另一方，常常導致意外結果。

+++

+++我已經啟用薄膜功能，但看不到任何效果。 我漏掉了什麼？

先檢查厚度值。 反直覺的是，較薄的數值會產生更明顯的虹彩——大多數效應發生在0到1微米之間。 如果影響仍然微弱，調整IOR，這會改變干涉的強度和顏色。 也要確認薄膜重量是否高於零。
