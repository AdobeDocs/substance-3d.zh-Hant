# Corona - 物質畫家

用 Corona 渲染時，你可以使用 Substance Painter 或 Substance 插件匯出的貼圖。 Corona 採用 Specular/Glossiness 工作流程，並搭配 1/IOR 映射。 你需要以下地圖：

* 擴散
* 反射（鏡面）
* 光澤度
* 1/IOR（改裝）

使用 Corona 輸出範本，Substance Painter 會匯出所需的轉換地圖類型。

![](../../../assets/corona-paintetr.png)

>[!NOTE]
>
> 代表資料的地圖必須被正確解讀。 更多資訊請參閱 [色彩管理](../../../renderers/color-management/color-management.md)頁面。
