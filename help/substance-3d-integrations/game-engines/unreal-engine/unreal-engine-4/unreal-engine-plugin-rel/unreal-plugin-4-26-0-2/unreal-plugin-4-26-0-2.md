# Unreal 外掛 4.26.0.2

補充：

* Substance Engine v 8.0.3 支援
* Substance Source 動作現在會進入 Substance Launcher 內的 Source 標籤，允許資產直接傳送到 UE4（[更多細節](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md)）
* 在升級專案版本時，處理的物質材料數量減少

修正：

* 在 Mac 上，當關閉安裝 UE4 Substance 外掛的編輯器時，UE4 會當機
* 在 Substance Graph 實例中更改文字參數會導致凍結並最終當機
