# Unreal 外掛 5.0.1

更新/新增：

* 支援 Unreal Engine 5.0.0+ 版本
* Unreal Engine 5 插件文件
* 支援新的三平面材質範本
* 支援新的「實體尺寸」功能
* *重新設計* 物質標準範本與物質折射範本
* 修改世界空間 XYZ 值的能力
* Python 腳本
* 自動設定實體大小的材料節點，並以物質輸出的數值為準

已移除：

* UE 5 插件中的 float4 參數

修正：

* 當材質參數透過藍圖調整時，封裝版 UE5 專案會當機
* 當 Substance Graph 實例的輸出未被勾選時，外掛會關閉參數視窗
* 修正了偶爾導致參數變更延遲的渲染延遲
