# Unreal 外掛 5.3.2

2023年12月4日發行

<b>固定</b>

* 已解決 Substance 外掛在 Mac 上無法運作的相容性問題，適用於 Unreal Engine 5.3。
* 修正了 Unreal Engine 的 Substance 插件中取消選取材質通道不再導致當機的問題
* 解決了插件中「stone-arc.sbars」材質在輸入區塊下只顯示「輸出尺寸」選項的問題，而非完整顯示可修改材質屬性
* 修正了 Substance 插件中的色彩偏移問題，匯入材質顯示錯誤、紅移的法線和非顏色的基底貼圖。
* 修正了 Substance 插件中一個當機問題，當我在 .sbsar 檔案上使用「重新匯入」會導致編輯器當機。
* Substance 插件的輸入驗證功能提升，防止關鍵材料屬性欄位出現超出範圍或無效的條目。」
* 修正了一個錯誤，就是在 Substance 外掛建立第二個圖形實例時，會移除所有先前載入的預設。」
* 修正了一個重新匯入 Substance Factory 實例會移除所有現有預設的問題。
