# Substance 輸入映像 - UE5

物質可以透過輸入產生，提供影像後再處理。 這讓你能建立模組化材質，將烘焙的網格資料或圖案作為輸入，來變更或確認材質到資產中。

* 你可以用 UTexture2D 搭配 Substance 輸入。
