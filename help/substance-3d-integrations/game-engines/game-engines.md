# 遊戲引擎

大多數主流引擎可以透過 Substance 插件匯入 Substance 檔案（.sbsar）。

* <b>Unity</b> 在 2017 年發行週期中原生整合了 Substance 外掛。 針對 Unity 2018 及以上版本，Substance 插件可在 Unity 資產商店](https://assetstore.unity.com/packages/tools/utilities/substance-in-unity-110555)取得[。
* <b>Unreal Engine</b> 外掛可以在 Unreal 市集](https://accounts.unrealengine.com/logout?redirectUrl=https%3A%2F%2Fwww.unrealengine.com%2Fmarketplace%2Fsubstance-plugin)找到[。
* <b>Lumberyard</b> 的外掛是原生整合的。
* <b>CRYENGINE</b> 外掛由 Crytek 原生整合並維護。欲了解更多資訊，請參閱 [Substance CRYENGINE 文件](https://docs.cryengine.com/pages/viewpage.action?pageId=44968527)
