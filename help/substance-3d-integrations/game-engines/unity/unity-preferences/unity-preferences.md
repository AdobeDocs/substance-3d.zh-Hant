# Unity 偏好設定

Adobe Substance 3D 偏好設定視窗允許你設定外掛的使用者自訂選項。

**產生所有圖輸出** - 每個圖都會產生所有圖輸出。

**材質解析度** - 每個圖產生材質的預設解析度

**CPU 最大解析度** - 使用 CPU 引擎時支援的最大貼圖解析度。

**Substance 3D 資產** - 連結到《Substance 3D Assets》頁面。

**Substance 3D 社群資產** - 連結至 Substance 3D 社群資產頁面。

**關於** - 顯示外掛版本資訊。
