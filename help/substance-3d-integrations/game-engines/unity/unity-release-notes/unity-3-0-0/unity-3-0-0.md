# Unity 3.0.0

2021年6月27日發行

更新/新增：

* Apple Silicon 支援
* 新的 YouTube 教學，教你如何使用這個插件
* 新的腳本文件
* 在 Substance Graph 編輯器及主 Substance 檔案編輯器中支援 control-z
* 載入大量 SBSAR 檔案時效能提升
* 支援多圖物質材料
* 更改了 Substance 圖表管理的介面
* 透過 C 載入預設的 Exposed API#
* 更新的線上文件

修正：

* 反覆按隨機按鈕時，檢查器顯示會出現錯誤
* Null 材質輸入破壞 Substance 更新
* 「產生所有輸出」、「產生 MIP 映射」和「僅執行時」切換功能無法運作
* 命名空間的問題
* 進入遊玩模式並選取圖形資產時，會出現空參考錯誤
* 在使用僅執行時材質的 2021.3 最新 Unity LTS 版本中，HDRP 和 URP 出現問題
* 多輸入的 SBSAR 檔案效能問題
* 「The Handle 已發布」錯誤
* 「遊戲模式進入時藍色移位」問題
* SBSAR 檔案的高度圖問題
* 影像輸入讀取無法辨識的貼圖的問題

已知問題：

* 修復 Mac 版本輸出材質的 R 與 B 通道會被翻轉的問題
* Mac 的重大效能提升
