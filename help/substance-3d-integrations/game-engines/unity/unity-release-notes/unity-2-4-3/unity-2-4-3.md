# Unity 2.4.3

2019年12月發行

錯誤修正：

* 修正：法線貼圖反轉
* 已修正：Inspector 內啟動垂直位置問題
* 修正：Inspector Graph「生成材質」區塊中的滾動條處理。 除錯文字清理
* 已修正：平台解析度懸停文字中出現「PC、Max， and Linux」拼字錯誤
* 已修正：更改平台解析度設定並點擊材料導航按鈕時出現錯誤
* 已修正：HDRP 打包無法正確處理 AO。 遮罩貼圖綠色通道為黑色
* 已修正：（回歸分析，僅限 Mac 版）數值輸出/實體若無有效材質貼圖會讓 Unity 當機。
* 已修正：更改參數並點擊另一個物質實例時會當機。
* 已修正：點擊主 Substance 物件後再點擊 Substance 圖表時（僅限 2019.2+ 版本）GUI 錯誤
* 已修正：Unity 2019.3 sbsar 檔案匯入錯誤
* 已修正：除非腳本中有渲染呼叫，否則 Duplicate（） 函式不會完全渲染 Substance
