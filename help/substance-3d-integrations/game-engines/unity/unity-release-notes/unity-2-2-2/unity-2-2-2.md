# Unity 2.2.2

## 2.2.2 發行說明

**發行日期：2019/2/11**

### 核心外掛：

* 修正了一個錯誤，就是安裝 Substance In Unity 外掛時，Unity 預設的材質介面被覆寫了
  * 修正了一個 EditorApplication.delayCall 設定時會引起其他插件問題的錯誤
  * 修正了在專案名稱中使用非拉丁字母時發生的當機
