# Unity 2.4.1

## 錯誤修正/更新：

* 使用 HDRP 時，生成的 HDRP 材質上的金屬值設為 0。 修正後預設是 1.0。
* HDRP 遮罩輸出設定為 sRGB - 已修正為停用 sRGB
* 非物質材質不再啟用讀寫功能
* Android 現在正式支援 64 位元。
* 修正物質來源在 Mac OS 上無法載入
