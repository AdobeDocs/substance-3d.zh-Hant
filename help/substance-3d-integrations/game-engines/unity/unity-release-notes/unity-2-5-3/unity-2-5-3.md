# Unity 2.5.3

2020年11月4日發行

修正：

* 在更改 Specular 地圖的打包時會當機
* 在標準 3D 專案中，鏡面貼圖在 Alpha 通道中沒有填充平滑度
* 刪除 Library 資料夾後，重啟 HDRP/HRP 專案時當機
* 重複材質缺少已分配的著色器和材質屬性
* 場景與預製檔中行尾角色的變更。

已知問題：

* 無法穩定地從 Unity 的 Source 下載資產。 解決方法是從 [Substance Source 網站](https://source.substance3d.com/) 下載素材，然後手動匯入素材。
