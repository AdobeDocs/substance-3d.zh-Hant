# Unity 2.5.4

2020年12月9日發行

修正：

* 當 Substance 材料包含在 Unity 專案中時，無法產生相容的 iOS 應用程式

已知問題：

* 無法穩定地從 Unity 的 Source 下載資產。 解決方法是從 [Substance Source 網站](https://source.substance3d.com/) 下載素材，然後手動匯入素材。
* Unity 2020.2 及以上版本目前不支援
