# 專案間共享 sbsar 檔案

使用 .sbsprs 檔案可以在專案與電腦間共享 .sbsar 檔案，同時保持相同的參數調整。

在原始專案的材料被修改成將分享的設定後，前往檢查面板中的預設設定。 在預設設定裡，建立一個新的預設並命名它。 這個新命名的預設會出現在本素材的預設列表中。 完成後，匯出預設並儲存在本地。

在其他專案或電腦中使用 .sbsar 時，也請附上匯出的預設檔。 當 sbsar 匯入 Unity 專案後，進入預設設定並選擇匯入選項。 選擇前一步的預設檔並匯入。 應該加入一個包含前一個專案設定的預設。

所有共用的資料都重複此步驟。
