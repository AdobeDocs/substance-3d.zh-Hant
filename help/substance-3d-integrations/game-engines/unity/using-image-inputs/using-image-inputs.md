# 使用影像輸入

為了在物質的輸入參數中使用影像：

1. 在 Substance Graph 的檢查視窗中，你可以選擇專案中的貼圖，指派給影像輸入。

   ![](../../../assets/imageinput-inspector.png)
1. 請注意，選擇貼圖時，貼圖的「Read/write Enabled」欄位會被勾選，因為這是將貼圖資料讀入 Substance 材質所必須的

   ![](../../../assets/imageinput-texture.png)
