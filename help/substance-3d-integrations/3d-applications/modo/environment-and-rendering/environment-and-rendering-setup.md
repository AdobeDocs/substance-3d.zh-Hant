# 環境與渲染設定

## 環境設定與渲染

為了在物理基礎渲染和進階視窗設定中獲得最佳效果，你需要在環境中使用 HDR 貼圖。 MODO 附帶多個環境預設，可以在 Layout 標籤中找到。\
一旦你載入了 HDR 環境，就需要設定進階視窗的光影和背景選項。 你可以按 O 鍵調出 3D 視窗屬性，然後在進階選項中設定\
光影與環境轉為環境選項。 或者，如果你有場景燈光，也可以用 Scene + Environment 來做光照。

![](../../../assets/env.png)

## 重要性抽樣

Substance Designer 3D 視口使用重要性取樣。 為了獲得最佳渲染效果，你應該啟用 MODO 渲染器的重要性取樣。 你可以在渲染設定的全域光照標籤籤裡做這件事。
