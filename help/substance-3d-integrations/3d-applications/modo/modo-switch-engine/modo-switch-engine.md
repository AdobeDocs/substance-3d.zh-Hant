# Modo Switch 引擎

## 切換物質引擎

Substance Engine 有兩個版本，分別是 CPU 和 GPU。 GPU 引擎用來製作超過 2K 的貼圖。 CPU 引擎只能產生最高 2K 的貼圖。 如果你需要更高解析度的材質，就需要切換到 GPU 引擎。

在物質套件選單中進入物質設定選項，選擇切換物質引擎。 你需要重新啟動 MODO 才能啟用 GPU 引擎。 此設定呈現全域偏好。 每次執行 MODO 時，GPU 引擎都會被啟用，直到手動切換為止。

>[!NOTE]
>
> **使用 Substance GPU 引擎需要一顆 1GB 或以上的獨立顯示記憶體。 不支援整合式 GPU。**\
> Nvidia：GeForce 650M 1GB 或以上\
> AMD：6870M 或更高
