# Modo 安裝

安裝外掛時，只要將 LPK 檔案拖到 MODO 中即可。 如果你還沒安裝套件或 MODO 內容包，可能會跳出對話框，要求你建立相應的資料夾。 套件安裝完成後，你會在MODO介面右上角看到一個Substance按鈕。
