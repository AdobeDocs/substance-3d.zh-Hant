# 使用預設

Substance 檔案可以包含嵌入的預設檔案。 如果 Substance 有嵌入的預設檔，它會出現在 Substance 預設視窗中。 你也可以根據你選擇的物質參數設定，建立自己的預設。

![](../../../assets/max9.png)

1. Create Preset 會根據你在 3ds Max 中為 Substance 設定的參數設定，建立一個新的預設。
1. 匯入預設會匯入一個預設檔案（.sbsprs）。
1. 儲存預設會儲存目前所選預設的參數值。
1. 匯出選擇預設會將預設匯出成預設檔（.sbsprs）。
1. 移除所有預設會移除預設列表中的預設。
1. 移除選取的預設只會移除所選的預設。
