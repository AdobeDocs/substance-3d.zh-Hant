# 批次匯入

你可以用批次匯入（Batch Import）來批次匯入多個 .sbsar Substance 檔案。

1. 到3ds Max介面頂端的Substance設定，選擇Substance Batch Import。
1. 選擇你想匯入的 .sbsar 檔案。
