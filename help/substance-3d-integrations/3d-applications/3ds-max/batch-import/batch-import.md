# 批次匯入

您可以使用批次匯入來來，對多個 .sbsar Substance 檔案進行批次匯入。

1. 前往 3ds Max 介面頂端的 Substance 設定，選擇 Substance Batch Import。

1. 選擇您想要匯入的 .sbsar 檔案。
