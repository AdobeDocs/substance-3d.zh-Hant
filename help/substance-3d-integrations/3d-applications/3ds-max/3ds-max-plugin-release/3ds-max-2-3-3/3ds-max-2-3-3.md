# 3ds Max 2.3.3

2020年6月3日發行

今天我們釋出了 2.3.3 版本的外掛，這是在 2.3.2 基礎上的錯誤修正版本。

2.3.3 發行：

* 外掛檔案由 SubstanceMax.dlt 重新命名為 substancemax.dlt
* 新增版本與描述資訊至內容_link.dll
* 已修正 Redshift 檢查版本的問題，現在應該能在 Redshift 3 上正常運作
* 修正了在將 SBSAR 載入 Substance 節點後，復原/重做時的當機問題
* 修正了設定對話框無法運作的回歸問題
* 修正載入包含非拉丁字元的 sbsar 檔案時當機

我們的發行流程也已全面重製，因此你們應該能期待比過去更大、遙遠的發行更頻繁的發行。

此版本於 2018、2019、2020 及 2021 年版 3ds Max 發行。
