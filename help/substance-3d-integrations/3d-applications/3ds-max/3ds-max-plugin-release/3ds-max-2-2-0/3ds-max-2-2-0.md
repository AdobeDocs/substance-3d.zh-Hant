# 3ds Max 2.2.0

發行日期：2019/06/4

* 新增對 3ds Max 2020 的支援
* 更新至 Substance Engine V7，新增對 Designer 2019.1 的價值處理器支援
* 插件現在會相對於自身載入 Substance 引擎
* 切換成 MSI 格式，並透過 Microsoft 工具進行正確的靜態安裝/卸載
* 安裝程式和檔案現在都已正確簽署
* 安裝程式不再修改原始插件的任何檔案
* 已修正 3ds Max 2019（及 2020）選單無法載入的問題
* 新增原生支援 ART 渲染器
* 修正了 Corona 工作流程腳本在沒有光澤輸出時的問題
* 工作流程腳本現在以純 .ms 檔案形式發佈，並可進行檢查
* 較小的外觀調整與穩定性提升
