# 3ds Max 2.4.0

2020年8月10日發行

補充：

* 新物質材料樣本

修正：

* 參數區塊碰撞

已知問題：

* 載入一個舊場景，並設定 Substance 物件的關鍵影格，然後在未儲存場景並重新開啟的情況下開啟曲線編輯器，3dsMax 會當機。 解決方法是將場景存到新版本的檔案，然後再重新開啟

此版本於 2019、2020 及 2021 年的 3ds Max 發行
