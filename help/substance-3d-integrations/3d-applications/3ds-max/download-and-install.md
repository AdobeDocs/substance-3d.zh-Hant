# 下載並安裝

最新版本的外掛程式由 Autodesk 原生發行，搭配最新相容的 3ds Max 版本。 如果你需要針對舊版本的特定版本，請在下方找到下載連結。

* **下載 Autodesk 3ds Max 2027 版：** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **下載 Autodesk 3dsMax 2026 版：** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **下載 Autodesk 3dsMax 2025 版：** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **下載 Autodesk 3dsMax 2024** （外掛程式版本 3.1.0）： <https://www.adobe.com/go/substance3d-3dsmax-win-2024>
