# 卸載外掛

要卸載該附加元件，請前往「編輯>偏好設定>附加元件」，並展開該附加元件的區塊。

1. 首先，用卸載工具&#x200B;**按鈕移除整合工具**。
1. 然後用 **「移除** 」按鈕移除附加檔案

>[!NOTE]
>
> 如果需要手動移除 Substance 整合工具，請從以下目錄刪除 Substance3DIntegrationTools 資料夾
> 
> * **Windows**：C：\Users\（username）\AppData\Roaming\Adobe
> * **Mac**：/Users/（用戶名）/函式庫/應用程式支援/Adobe/Substance3DIntegrationTools
> * **Linux**： /home/（username）/Adobe/Substance3DIntegrationTools
