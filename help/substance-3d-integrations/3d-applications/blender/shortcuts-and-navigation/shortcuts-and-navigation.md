# 捷徑與導航

捷徑清單可在附加偏好設定底部找到。 每個快捷鍵的快捷鍵綁定可透過輸入鍵欄位中所需的鍵來自訂。 每個快捷鍵也可啟用 Ctrl、Shift 和 Alt。

預設的按鍵綁定如下：

* **浮動選單** - CTRL + SHIFT + U
* **載入 SBSAR** - CTRL + SHIFT + L
* **套用目前材質** - CTRL + SHIFT + U
