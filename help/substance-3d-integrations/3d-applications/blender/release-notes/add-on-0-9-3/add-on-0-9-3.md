# 附加元件 0.9.3

**附加元件版本 0.9.3+ 的發行說明**

* 在附加設定中新增 OCIO 2.0 色彩空間標籤。
* 在參數工廠/輸出工廠中加入描述作為工具提示。
* 新增了整體的回報功能（移除了侵入性的彈出視窗，並以原生的 Blender 訊息取代）。
* 安裝和更新附加元件偏好設定時，請更新 SRE 版本標籤。
* 修正輸出大小和隨機種子在物質中並不總是存在的問題。

**偏好設定區：新增/更新：**

* Cycles/Eevee 物理尺寸作為預設著色器下拉選單的可用預設。
* 物理尺寸預設投影混合的控制。
* 我把支援連結改成指向 Discord 伺服器。
* 在附加元件偏好設定中修正顯示正確且目前 SRE 版本的設定。
* 如果需要更新，請顯示所有相容版本的外掛。
* 當缺少 SRE 時，顯示支援版本陣列而非第一個版本。

**Substance 3D 面板區塊：新增/更新：**

* 材料的物理尺寸會顯示在圖參數下（以公尺為單位）。
* 週期/伊布的物理尺寸可從著色器下拉選單中取得。
* 如果所有參數都看不見，請隱藏參數群組。
