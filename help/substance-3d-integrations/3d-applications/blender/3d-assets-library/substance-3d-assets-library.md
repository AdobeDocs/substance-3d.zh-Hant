# Substance 3D 資產庫

數千個專業製作的素材及其他資產可於 [Substance 3D 資產頁面](https://helpx.adobe.com/substance-3d/unlisted/assets.html)下載。 社群免費分享的更多素材可在Substance 3D社群資產頁面[&#128279;](https://helpx.adobe.com/substance-3d/unlisted/community-assets.html)找到。

在 Blender 的 Substance 3D 面板中，你也可以點擊 Substance 3D 資產和 Substance 3D 社群資產按鈕，開啟瀏覽器到這些頁面。
