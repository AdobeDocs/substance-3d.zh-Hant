# 使用 Substance 插件

Substance 插件位於 Cinema 4D 插件選單中。

![](../../../assets/cinema-4d-1.png){width="500px"}

## 載入資產......

用這個把 Substance 資產載入你的場景。 僅能載入 Substance 檔案（.sbsar）。 若尚未顯示 Substance 資產管理，成功匯入 Substance 後會自動開啟。 這個指令也可以在 Substance 資產管理工具中找到。

匯入時可能會問你是否應該將 Substance 複製到你的專案資料夾。

![](../../../assets/cinema-4d-2.png){width="500px"}

* 如果你回答「否」，場景中會儲存一條通往物質的絕對路徑。
* 如果你回答「是」，Substance 會被複製到你的專案的 tex 子資料夾，在你的場景中只會以檔名來稱呼它。

這個提示每次匯入只會出現一次（例如，當從 Explorer 或 Finder 拖放多個物質時）。
