# 設定

## 需求

必須具備 Cinema 4D R16 或以上的機型。 除了 Cinema 4D Lite 外，所有產品版本皆被支援。

物質檔案可透過 [Substance Designer](https://www.allegorithmic.com/products/substance-designer) 建立。

## 安裝

## 窗戶

1. 安裝時不應該運行 Cinema 4D。
1. 執行自動安裝套件。
1. 選擇/檢查目的地資料夾。 這應該是安裝 Cinema4D 的資料夾，而不是插件子資料夾。
1. 點選「安裝」。
1. 成功安裝後，您將獲得啟動 Cinema 4D 的選項。

## Mac OS X

1. 安裝時不應該運行 Cinema 4D。
1. 把 can 檔丟到 Cinema 4D plugins 資料夾裡。
1. 照常啟動 Cinema 4D。
