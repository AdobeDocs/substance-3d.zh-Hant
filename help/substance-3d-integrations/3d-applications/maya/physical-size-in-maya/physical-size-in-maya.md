# 瑪雅的物理尺寸

Maya 的實體尺寸功能允許你使用與實體材質相同大小的數位材質，並將它們貼平貼或重複覆蓋在模型上，尺寸合適。 這對於時尚、運動服飾、室內設計，以及電影和遊戲服裝設計都非常有用。

在 Maya 建立你選擇的渲染器節點後，你可以在 Substanace UI 啟用實體尺寸功能，這會在每次 Substance 輸出後建立一個三平面投影節點，並將投影大小調整到捕捉時所記錄材質的物理尺寸。

請參考以下教學，了解如何使用此功能的詳細資訊。

## 此功能目前適用於：

Maya 2018、2019、2020、2022 及 2023 版，適用於 Linux、macOS 與 Windows

Maya LT 2018、2019 和 2020 在 macOS 和 Windows 上。
