# Maya 2.1.6

2020年9月22日發行

變更清單：

* 升級至相容 Substance Engine v.8.0.2，支援 Designer 2020.2 新增節點

此版本於 Linux、MacOS 與 Windows 的 Maya 2017、2018、2019 及 2020 版本，以及 MacOS、Windows 上的 Maya LT 2018、2019 和 2020 版本
