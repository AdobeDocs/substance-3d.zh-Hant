# Maya 2.4.0

<b>新增/更新：</b>

* 將 Substance 引擎升級至 Maya 外掛的第 9 版，提升效能與相容性。

<b>修正：</b>

* 修正了 Maya 2023 中一個關鍵問題，該問題是用 Substance 引擎 9 版或更早版本的 sbsar 檔案建立網路時，應用程式當機，確保了這些檔案的網路建立穩定。

Maya 2.4.0 於 Maya 2020、2022 及 2023 平台於 Linux、macOS 及 Windows 平台發行
