# 瑪雅 2.1.2

2020年6月2日發行

今天我們釋出了外掛的 2.1.2 版本。

唯一的變動是：

* 在 Maya LT 建立 Stingray 著色器網路時修正了錯誤。

這也隨 Maya 2020.2 發布，並包含在 Maya 安裝程式中。

它同時在 Maya 2017 - 2020 及 Maya LT 2018 - 2020 平台發行
