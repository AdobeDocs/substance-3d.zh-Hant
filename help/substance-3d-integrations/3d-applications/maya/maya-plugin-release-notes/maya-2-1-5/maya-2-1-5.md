# Maya 2.1.5

2020年8月5日發行

變更清單：

* SBSAR 檔案現在應該會顯示，並且可以在檔案路徑編輯器中設定
* 檔案路徑應該由 Maya 的相對單位設定，當是分享專案時
* 從 Substance Launcher 發送時，SBSAR 檔案會被複製到專案目錄中

此版本於 Linux、MacOS 與 Windows 的 Maya 2017、2018、2019 及 2020 版本，以及 MacOS、Windows 上的 Maya LT 2018、2019 和 2020 版本
