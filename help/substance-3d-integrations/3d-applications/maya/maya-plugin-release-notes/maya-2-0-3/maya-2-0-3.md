# Maya 2.0.3

該外掛的 2.0.3 版本現已在 [網站上](https://www.substance3d.com/ecosystem-plug-ins/substance-in-maya/)發布。

變動：\
\* VRay 工作流程現在會設定 Vray 材質使用粗糙度\
\* 更新了一些新 substance3d 網站的連結。\
\* 已將Substance Engine版本加入關於選單\
\* 新增腳本指令以查詢 Substance Engine 版本\
\* $pixelsize輸入不再當機\
\* 在 Designer 設定的值輸入現在會在節點上顯示，就像圖片輸入一樣\
\* Redshift 工作流程腳本現在將 brdf 設為 ggx，並讓 bump 節點使用切線空間法線\
\* 新的 Renderman 工作流程腳本，以更好地符合預期使用需求\
\* substanceSetWorkflow 指令現在正確地接收一個字串參數\
\* 新增對 Maya 2020 的支援

2.0.3 目前已於 Windows、MacOS 及 Linux 平台的 Maya 2018、Maya 2019 及 Maya 2020 版本中發布。 它也在 Windows 和 MacOS 上的 Maya LT 2018、Maya LT 2019 和 Maya LT 2020 發行。
