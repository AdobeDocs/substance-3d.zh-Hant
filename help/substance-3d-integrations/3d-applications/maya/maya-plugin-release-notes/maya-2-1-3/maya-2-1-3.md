# Maya 2.1.3

2020年6月17日發行

今天，我們釋出了外掛的 2.1.3 版本。

2.1.3 發行：

* 安裝程式現在在 Windows 上以 SHA-256 簽署
* 安裝程式內的所有二進位檔現在都是在 Windows 上登入的
* Substance\_link.dll 和 Substance\_portal\_cli.dll 現在在 Windows 上有版本/描述資訊
* 在 Maya 2020 新增了標準 Surface 的工作流程選項

此版本於 Maya 2017、2018、2019 及 2020 年在 Windows、Linux 及 MacOS 平台發行。 它也在 Windows 和 MacOS 上的 Maya LT 2018、2019 和 2020 平台發行。
