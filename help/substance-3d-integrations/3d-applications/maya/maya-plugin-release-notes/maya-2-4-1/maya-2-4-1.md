# Maya 2.4.1

<b>新增/更新：</b>

* Maya 外掛現在預設使用 GPU，顯著提升了效能與渲染速度。

<b>修正：</b>

* 修正了 Maya 外掛「關於內容」選單中的連結，導向正確的版本說明頁面，現在正確指向 https://helpx.adobe.com/substance-3d-integrations/3d-applications/maya/maya-plugin-release-notes.html。
* 解決了 Maya 插件中一個問題，重置材質後，UI 顯示的解析度值無法更新，確保所有數值（包括解析度）都能正確重置為預設狀態。

Maya 2.4.1 於 Linux、macOS 及 Windows 平台推出 Maya 2020、2022 及 2023 版本
