# 瑪雅 2.2.3

變更清單：

* 新增對 Arnold 7.1.0/MtoA 5.1.0 的支援，適用於 Maya 2019、2020 及 2022
* 新增一個腳本指令「substanceNodeGetGraphMetadata」，以腳本中的 XML 字串取得 Substance 圖的元資料
* 在腳本呼叫中查詢越界圖不再當機
* Arnold 和 MtoA 外掛現在安裝在一個目錄中，使用 &#39;-&#39; 分隔符在語意版本號之間
* 引擎資源設定現在被適當地尊重，修正了被忽略的回歸問題。

1. 2.3 版本發佈於
1. Maya 2017、2018、2019、2020、2022 和 2023 版，適用於 Linux、macOS 和 Windows
1. macOS 與 Windows 上的 Maya LT 2018、2019 與 2020
