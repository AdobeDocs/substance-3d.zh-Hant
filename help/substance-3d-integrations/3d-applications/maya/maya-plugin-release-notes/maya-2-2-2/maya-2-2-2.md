# 瑪雅 2.2.2

變更清單：

* Substance 3D 遠端引擎更新至 8.4.2
* 新增對 Maya 2023 的支援
* 在 Maya 2023 中新增對 Arnold 7.1.0/MtoA 5.1.0 的支援
* 使用 Arnold 工作流程「套用工作流程到貼圖」後，現在能正確辨識 Painter Arnold 模板中的「金屬度」貼圖
* 如果你套用預設，解析度下拉選單就會正確更新
* &#39;substanceRunImageWorkflow&#39; 指令現在會回傳最終建立的著色器
* &#39;substanceNodeApplyWorkflow&#39; 指令也會回傳最終建立的著色器
* &#39;substanceUtilityCreateAndLoad&#39; 指令現在會回傳它所建立的 substanceNode

1. 2.2 版本於 Maya 2017、2018、2019、2020、2022 及 2023 年在 Linux、macOS 及 Windows 平台發行
