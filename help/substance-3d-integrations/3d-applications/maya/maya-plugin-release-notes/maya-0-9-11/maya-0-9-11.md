# Maya 0.9.11

**Maya 2.0 變更：**\
**穩定性**：

* 動態屬性現在是從圖中原生建立，而非透過屬性編輯器程式碼
* Substance 節點可以在初始化時批次建立，不需要 UI 輸入
* 屬性編輯器與屬性編輯器明顯更穩定
* 記憶體效能大幅提升，足以讓 GPU 引擎支援 8k 輸出
* 設定/偏好設定現在會儲存成獨立的設定檔，方便在 Maya 外編輯

**腳本：**

* 強腳本 API，支援從擷取輸入、圖形與輸出資訊、載入 sbsar 套件、變更圖形，到在預設管理器中執行任何預設操作
* UI 程式碼設計用來使用與公開腳本 API 相同的功能

**物質特徵**：\
**預設支援：**

* 在 Designer 中嵌入的預設會載入到 preset manager。
* 匯入與匯出 sbsprs 檔案，包含多個預設
* 預設管理器
* 引擎 V7 支援
* 已經能搭配即將隨 Designer 2019.1 發布的新 Substance 引擎運作
* 數值輸出會被渲染成 Maya 輸出屬性，映射在
* 圖形/實體節點，可以插入超陰影中的其他節點

**工作流程系統：**

* Arnold、Renderman、VRay、Corona 等新工作流程
* Python 中的自訂工作流程擴充
* 從 hypershade 反向執行工作流程腳本，設定一次自訂工作流程並存檔
* 使用Substance Painter的影像映射工作流程

**使用者介面與使用者體驗的改進：**

* 檔案 -> 匯入 .sbsar 會建立一個物質節點
* 將 sbsar 檔案從檔案瀏覽器拖放到 hypershade 以建立 substance 2 節點
* 屬性現在由 Designer 中設定的類別來規劃

**其他改進：**

* 影像輸入現在可以與程序節點合作
* 現在可以設定程序節點的取樣率，使其能下取樣或上取樣程序影像輸入
* 輸出節點現在會顯示以 Substance Designer 編碼的輸出資訊
* Substance/Graph 節點現在可以顯示圖資訊（作者等）
* 層覆寫支援，例如連線覆寫與屬性覆寫
* 快取到磁碟會選擇 exr 檔案類型來處理任何 HDR 輸出，這些輸出是 16 位元、16 浮點點或 32 位元浮點
* 舊外掛的反射
* 用新插件載入場景會將舊的圖和輸出節點轉換成 substance 2 節點
