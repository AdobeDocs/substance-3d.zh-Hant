# 瑪雅 2.3

變更清單：

* 新增了一個啟用實體尺寸的模式。 這會將三平面投影計算加入節點網路，並可切換開關
* 新增腳本指令，包括 substanceUtilityActivatePhysicalSize 以啟用或停用物理大小，以及 substanceUtilityResetPhysicalSize 以在修改時重置投影值。
* 新增了 substanceNodeGetPhysicalSize 指令，以取得圖形的物理大小值。
* 新增了啟用/停用以及重置的勾選框和按鈕。 在屬性編輯器中新增了 Substance 圖的實體大小顯示。
* 新增設定以全局啟用實體尺寸功能
  * 如果啟用實體尺寸功能，渲染器的工作流程就會支援建立這些投影節點
* 已移除對 Maya 2017 的支援

1. 3 是為
1. Maya 2018、2019、2020、2022 及 2023 版，適用於 Linux、macOS 與 Windows
1. macOS 與 Windows 上的 Maya LT 2018、2019 與 2020
